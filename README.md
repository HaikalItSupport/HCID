# HCID

Aplikasi web untuk **Daftar IP Address Sistem Pusat Komando TMC** yang bisa dibuka di Mozilla Firefox maupun Google Chrome.

## Fitur
- Menampilkan data awal 17 lokasi TMC (lokasi, video, recorder, username, password, status).
- Tambah data kamera baru.
- Hapus data kamera.
- Penyimpanan data di browser (`localStorage`).

## Cara menjalankan
1. Buka file `index.html` di browser.
2. Data awal akan langsung tampil pada tabel.
3. Tambah atau hapus data sesuai kebutuhan.
