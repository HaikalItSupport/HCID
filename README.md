# HCID

Aplikasi web sederhana untuk menyimpan data kamera CCTV (IP kamera, username, dan password) yang bisa dibuka di Mozilla Firefox maupun Google Chrome.

## Cara menjalankan
1. Buka file `index.html` langsung di browser.
2. Isi form kamera lalu klik **Simpan Kamera**.
3. Data tersimpan di browser menggunakan `localStorage`.
